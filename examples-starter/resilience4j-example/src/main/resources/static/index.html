🛡️ Resilience4j 示例

测试熔断器、限流器、重试、舱壁、时间限制器等功能

⚡ 熔断器 (Circuit Breaker)
当失败率超过阈值时自动熔断，防止故障扩散
🚦 限流器 (Rate Limiter)
限制请求速率，每秒最多5个请求
🔄 重试 (Retry)
失败后自动重试，最多3次
🚢 舱壁 (Bulkhead)
限制并发调用数，最多3个并发
⏱️ 时间限制器 (Time Limiter)
超时控制，超过2秒自动超时
🎯 组合使用
同时使用重试、熔断器、限流器
