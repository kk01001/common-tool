📚 什么是数据权限?

数据权限是一种细粒度的权限控制机制,它可以在 SQL 查询时自动添加过滤条件, 确保用户只能访问其有权限查看的数据。MyBatis Plus 提供了强大的数据权限拦截器, 可以轻松实现基于部门、角色等维度的数据隔离。

💡 功能特性

  • 自动在 SQL 中添加数据权限过滤条件
  • 支持多种权限类型(本人、本部门、本部门及下级等)
  • 基于注解的权限配置,使用简单
  • 支持自定义权限处理器
  • 与 MyBatis Plus 无缝集成

📝 代码示例

使用 @DataPermission 注解配置数据权限:

// 在 Mapper 方法上添加数据权限注解 @DataPermission( type = DataPermissionType.SELF_AND_SUB, column = "department" ) List<User> selectUserList(); // 或在 Service 方法上使用 @DataPermission( type = DataPermissionType.SELF, column = "user_id" ) public List<User> getUserList() { return userMapper.selectList(null); }

🔧 配置说明

在 application.yml 中配置数据权限:

# MyBatis Plus 数据权限配置 mybatis-plus: data-permission: enabled: true # 默认权限类型 default-type: SELF_AND_SUB # 权限字段映射 column-mapping: department: dept_id user: user_id
